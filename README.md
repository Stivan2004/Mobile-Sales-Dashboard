# 📱 Mobile Sales Dashboard Using Power BI

📊 **Project Overview**

The Mobile Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. The main objective of this project is to analyze mobile phone sales data and understand sales performance across different cities, brands, mobile models, payment methods, and time periods.

This dashboard provides important business insights through interactive charts, graphs, KPI cards, and filters. It helps users monitor sales performance, identify popular mobile models, analyze customer ratings, and understand customer payment preferences.

## 🎯 Project Objectives

* Analyze total sales and total quantity sold.
* Track the number of transactions and average sales.
* Compare sales performance across different cities.
* Analyze mobile sales by brand and mobile model.
* Understand monthly and daily sales trends.
* Analyze customer ratings and payment methods.
* Provide interactive filters for better data analysis.

## 📊 Dashboard Features

**1. KPI Cards**

* Total Sales
* Total Quantity
* Total Transactions
* Average Sales

**2. City-Wise Sales Analysis**
Displays sales performance across different cities to identify high-performing locations.

**3. Monthly and Daily Sales Analysis**
Shows sales trends over different dates and months to understand changes in sales performance.

**4. Brand-Wise Sales Analysis**
Compares sales across mobile brands to identify the contribution of each brand.

**5. Mobile Model Analysis**
Highlights sales performance for individual mobile models.

**6. Customer Ratings Analysis**
Analyzes customer ratings to understand customer satisfaction.

**7. Payment Method Analysis**
Displays transactions by payment methods such as Cash, UPI, and Debit Card.

**8. Interactive Filters**
Allows users to filter dashboard information by month, mobile model, brand, and payment method.

## 🛠️ Tools and Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel
* Data Cleaning and Transformation
* Data Visualization

## 💡 Project Outcome

This project transforms raw mobile sales data into meaningful business insights. The interactive dashboard helps users understand sales trends, compare product performance, identify important markets, and analyze customer purchasing behavior.

It also demonstrates practical skills in data analysis, dashboard development, data visualization, and business intelligence.
